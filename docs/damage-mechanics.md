# ダメージ早見表の計算範囲

更新: 2026-10-11。対象は保存済みChampions M6、341フォーム、215特性。データ更新そのものは今回行っていない。

## 今回の監査への対応

| 監査項目 | 計算・表示 |
| --- | --- |
| ボディプレス、イカサマ、サイコショック | B参照、相手A参照、C対Bを個別に解決。ボディプレスはBの育成行、イカサマは相手Aの育成行を表示する。防御を参照する特殊技にも防御特性を適用する。 |
| フリーズドライ、フライングプレス、レイジングブル | 技固有の相性と正確なパルデア各種IDを処理。共有タイプ相性表の通常定義は変更しない。 |
| シェルアームズ | 各育成セルで物理・特殊の結果を比較し、大きい方を採用。選択した分類で接触性も変える。 |
| 確定急所、能力ランク、てんねん | 技由来の急所、急所防止、負の攻撃ランク・正の防御ランク無視、壁無視、スナイパー、防御ランク無視技を計算する。 |
| デカハンマー | 説明の「連続で出せない」を連続攻撃と誤認する除外を撤廃する。 |
| しめりけ、テイルアーマー、じょおうのいげん、ぶきよう | 技の使用禁止、優先度、道具無効を扱う。しめりけは場に残る使用禁止なので、かたやぶりでも消さない。 |
| 条件付き威力・状態異常 | 道具の有無と除去可否、被弾回数、倒れた味方数、上昇ランク、行動順、前の技の失敗、残りHP、状態異常、やけど、強化分岐を指定できる。 |
| 天候・フィールド・じゅうりょく | 技のタイプ／威力、通常炎水補正、砂の岩特防・雪の氷防御、接地判定、先制技防止、ノーてんき、メガソーラー等を扱う。 |
| ダブル | 複数対象補正は実際の対象数で判定する。味方特性は本人の特性と別入力。フレンドガード・はがねのせいしん・プラス／マイナス・フェアリーオーラ・てだすけ・壁を扱う。 |
| ちからずく | Championsの技説明を照合した追加効果対象IDを保持する。確定急所、単なる威力分岐、自身の能力低下は対象にしない。将来の対象技は手動指定を用意する。 |
| 発動後の能力・コピー・フォルム | 能力変化系特性は発動後のランクを指定する。トレース／レシーバーはコピー先の特性を指定。かわりものは比較相手の能力・タイプをコピーしHPは本人。バトルスイッチは攻撃時ブレード、防御時はフォーム指定。マイティチェンジとモルペコも現在フォームを指定する。 |
| 連続技・おやこあい | ヒット数と各発の乱数・丸めを扱う。HP、ばけのかわ、満タン限定効果、きあいのタスキ、半減きのみ、じきゅうりょく／くだけるよろいを各発で更新する。ドラゴンアローの2匹への振り分けは片方に1発として指定する。 |
| 体重・HP・素早さ依存 | 同じChampions snapshotから体重を生成。ヘヴィメタル／ライトメタル、HP比、素早さの育成・ランク・天候特性・まひ・スカーフ・くろいてっきゅう・おいかぜを参照する。 |
| 固定・割合・反撃・一撃必殺 | 通常威力式へ入れず別経路で計算する。ふくろだたきは参加者の攻撃種族値、反撃技は適切な攻撃で受けたダメージ、なげつけるは道具／道具威力を指定。一撃必殺は命中率付きの別表記。 |
| 威力・確定数の表示 | 見出しは補正後威力。HP依存などはセルの育成で数値が変わり得る。固定・割合技は威力1と表示しない。状態が変わる攻撃から単純な割り算で繰り返し回数を断定せず「命中1回」とする。 |
| 丸め | 乱数・STAB・相性を段階別に処理する。威力／最終補正は4096固定小数点で合成する。基礎46、STAB、4倍弱点の最低乱数は232。 |

以前の非表示35種類をすべて表示対象へ戻し、TOP10内の攻撃技は289種類を扱う。変化技はダメージ表へ含めない。

## 入力の意味と範囲

レベル50・個体値31、技が成立して命中した場合の直接ダメージを比較する。HP割合表示の分母は最大HP。連続技は指定した数が命中した場合の合計で、命中失敗の確率をダメージ幅へ混ぜない。きまぐレーザーは通常／30%で発生する強化を切り替える。

登場順・交換履歴・ランダムな能力変化の履歴から現在の状態を推測する対戦シミュレーターではない。天候・フィールド・能力ランク・コピー先・交代済み／発動済み状態は利用者が入力する。交代でリセットされるふんどのこぶし等の履歴は、ポケモン変更時の条件リセットまたは詳細条件リセットで戻す。

回復、反動、接触による反撃、ターン終了時ダメージ、技後の追加状態は合計に含めない。反撃技の受けたダメージには、その技が反撃できる分類・ターンのダメージだけを入力する。ふくろだたきには、ひんし・状態異常で参加できない味方を含めない。

Championsの説明・同一snapshotのmetadataを照合し、計算モデルの回帰テストを追加している。全組み合わせを実機で照合したという意味ではない。特にシェルアームズの判定細部や連続攻撃の追加効果などは、実機証拠が得られた時に回帰ケースへ追加する。

## データ更新

`data/damage-chart/mechanics.json`はusage-rankingと同じ`champoutCommit`の`masterdata/personal.json`・`parse/personal_dump.txt`・`masterdata/waza.json`から生成する。技の優先度と複数対象フラグも保持する。

`scripts/update-damage-chart-metadata.ts`はフォームIDと検証済みpersonalIdを結び付け、341フォームすべての種族値をsourceと比較する。未知フォームや不一致は失敗させ、通常種の体重を推測して埋めない。`npm run data:update`および既存の自動更新workflowに組み込む。単独更新は`npm run damage-data:update`。

道具は現在のChampionsデータに存在するものを扱う。前回レビューで例示したとつげきチョッキ等は、保存済み合法道具データに存在しないため追加しない。手動の追加倍率は、自動計算した道具とは別の明示的な仮定として保持する。
