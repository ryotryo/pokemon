# 役割分類の見直し

2026-10-12。保存済みChampions M6の341フォーム、旧31カテゴリの分類を見直した。新しいランキングデータへの更新は行っていない。

## 分類の基準

役割タグは、単にその技を覚えられるという意味ではなく、初心者向けに紹介する具体的な動きとして選ぶ。各フォームの特性・種族値・Champions learnableMoveIdsと記事の説明を照合する。全件の分類一覧と技・特性による照合を行い、紹介技だけでは判断できない場合は習得技や特性も確認する。

- 始動役と利用役を分ける。雨・晴れ始動は場全体の天候を特性で用意する役として紹介する。あまごい・にほんばれを覚えられるだけで始動例にはしない。
- 雨始動はペリッパー・ニョロトノ。すいすいのメガラグラージ、イダイトウ等は雨アタッカー。
- 晴れ始動はひでりのメガリザードンY・コータス・キュウコン。ようりょくそ、サンパワー、本人だけ晴れ扱いのメガソーラーは始動の根拠にしない。
- 砂始動はすなおこし・すなはき。すなかき・すなのちからは砂アタッカー。
- トリックルーム始動は技を使えるフォーム。バクーダ・メガバクーダは味方のトリックルームを利用するアタッカー。
- 攻撃して交代する技とバトンタッチ・しっぽきりを区別し、後者は交代支援として紹介する。
- クイックドロウの確率的な先行は、先制技を持つ根拠ではない。
- 条件付きの高速化だけを根拠に素の高速アタッカーにはしない。ポットデス・ウェーニバルは積み、ハカドッグ・ツンベアーは天候利用として説明する。
- イカサマは相手の攻撃を使うため、使用者自身の両刀火力の根拠にしない。クレッフィは壁・状態異常サポート、紹介技が特殊中心のペロリーム・ポワルン・ヒスイヌメルゴンは特殊型を紹介する。
- メタモンを安定した受け先として紹介せず、強化をコピーして切り返す積み対策として紹介する。

## 修正と検証

雨・晴れ・砂アタッカー、トリルアタッカー、交代支援、積み対策を追加し、計37カテゴリに整理した。クレッフィとペロリームは本文・紹介技の用途も分類と揃えた。Championsで除去技を持たないエアームドは設置物除去から除外した。ウェーニバルの先制技、ニョロトノの雨始動など、説明にある役割の抜けも修正した。

`tests/data/pokemon-roles.test.ts`で、全フォームに付いた天候・交代・壁・設置・除去・回復・トリックルーム等のタグについて、根拠となる特性または習得技があることを検証する。雨始動の2匹、利用役の混入防止、既存のメガ優先・各形式の使用率順・最大10匹を検証する。記事の紹介技も既存テストでChampions learnsetと照合する。

習得可能であることは実際の採用頻度の証明ではない。受け・高火力・サイクル等は技だけで機械判定できないため、説明・数値・特性を合わせた編集判断であり、すべての育成型を網羅する一覧ではない。今回の分類監査は全341記事の本文すべての事実を保証するものではない。
